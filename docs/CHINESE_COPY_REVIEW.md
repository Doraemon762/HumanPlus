## 请核对的表达

1. **Life Capture → 生活捕捉**：此为品牌叙事用语，技术领域并无唯一约定译法。当前统一为“生活捕捉”；可按品牌偏好改为“生活采集”或保留英文。
2. **World-Human Models → 世界—人类模型**：已按 V4 中文手册第 7 页确认。
3. **SuDA 的 support-based → 基于支撑集**：已核对 ICML 正式论文页，指预测函数的支撑集（supports of predictive functions），非泛指支持信息。
4. **CLOTHO 的 canonicalization → 规范化**：与 calibration（校准）区分。若团队采用“标准化映射”或“规范坐标映射”，请统一替换。
5. **Fast / Stable / Comfortable → 快速／稳定／舒适**：保留三词叙事与动效；中文译法供确认。
6. 研究论文中文题名均为工作译名，并非原出版物正式中文题名。原始英文数据与论文链接保留，未修改研究成果、作者、年份和数值。
7. 新闻中的“厦门大学 HumanPlus”延续此前确认的归属表述；研究机构与公司不能混为同一单位。媒体名“Xbotics 具身智能实验室”“具身智能前沿”为现有英文媒体名的中文表达，若有官方署名请提供。
